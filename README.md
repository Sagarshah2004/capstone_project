# 💸 Money Manager App

A responsive web-based application to manage personal finances by tracking income and expenses. Built using **HTML, CSS, and JavaScript (OOP)** with local storage support.


## 🚀 Features

### ✅ Core Functionalities

* ➕ Add transactions (Income / Expense)
* 📋 View transaction history
* ✏️ Edit transactions
* ❌ Delete transactions (with confirmation)
* 📊 Real-time financial summary:

  * Total Income
  * Total Expense
  * Net Balance



### 🔍 Smart Features

* Dynamic category selection (based on Income/Expense)
* Input validation with error handling
* Data persistence using **localStorage**
* Responsive and modern UI design


### 📊 Bonus Feature

* Interactive **Pie/Doughnut Chart**

  * Displays Income, Expense, and Savings
  * Toggle button to show/hide chart


## 🧠 Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & responsive layout
* **JavaScript (ES6)** – Logic & DOM manipulation
* **Chart.js** – Data visualization
* **LocalStorage** – Data persistence

## ⚙️ How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
3. Start adding transactions 🚀


## 📌 Validations Implemented

* Amount must be numeric and > 0
* Date cannot be in the future
* Category must be selected
* Description limited to 100 characters
* Error handling using `try...catch`
